# AI 闯关学习 · HTML 交互原型

## 打开方式

直接用 Chrome 或 Edge 打开 `index.html`。无需安装、联网或配置服务。

每个 HTML 均内嵌 CSS、JavaScript、矢量图标和示例数据，可单独打开；要使用分组之间的导航，请把 7 个 HTML 保存在同一个文件夹。

点击顶部“连续体验”，可从主题输入一路体验到闯关、复盘和分享预览。首次进入后可点击“机器学习是怎么‘学会’的？”填入示例主题。每张画板右上角的“单独体验”可以从该状态开始。

## 已实现的轻交互

- 主题与资料表单、文件信息展示、URL 校验；纯网页最多 10 个链接、混合任务最多 5 份来源。
- 来源模式切换、资料移除与失败重试，来源变更后要求重新整理。
- 5/10 题混合题组，或选择单一题型。自定义 3–10 题；单一题型受示例题库数量限制，页面会明确提示。
- 单选、多选、判断；提交前可改选，首次提交后锁定；漏选与错选分别标记。
- 即时讲解与来源依据；首次答案计算成绩和正确率；复习与重新挑战新建记录。
- 退出恢复、提前结束、AI 报告失败后的独立重试。
- 学习统计与历史记录联动；筛选、无数据状态、阶段报告生成与版本列表。
- 游客登录流程、协议确认、数据合并去重、同步状态。
- 分享字段开关、摘要预览、分享撤回；本地演示数据删除及 JSON 导出。
- 题目反馈和确认无效后的分母更正。

## 演示边界

所有题目、讲解、资料片段、用户与历史记录均为固定的“机器学习入门”样例。修改主题或选择自己的文件可以体验输入过程，但不会真正解析这些内容。生成阶段明确使用内置示例。

不会上传文件、联网检索、调用模型、登录微信或发送分享。原型中的删除仅改变演示数据，不会删除真实资料、文件或账户。

连续演示状态保存在浏览器 LocalStorage。点击弹窗顶部的重新开始按钮可恢复初始演示。浏览器对 `file://` 存储的隔离规则可能不同，跨分组的恢复效果以实际浏览器为准；单个连续体验流程不依赖跨文件同步。

## 修改与重新生成

- `assets/styles.css`：设计令牌、手机界面、桌面画板和响应式布局。
- `assets/data.js`：分组、题库、来源与历史示例。
- `assets/app.js`：60 个画板、状态管理、计分和轻交互。
- `build.py`：把以上源文件内嵌到 7 个 HTML。

修改后在该目录运行 `python build.py`。Python 只使用标准库。

## 验证

使用本机 Google Chrome 和 Playwright 完成检查。结果位于 `qa/verification.json`，截图位于 `qa/`。验证脚本为 `verify.cjs`，需要 Playwright 和本机浏览器；当前脚本提供本环境路径作为回退，可通过环境变量 `PLAYWRIGHT_MODULE` 和 `CHROME_PATH` 覆盖。

覆盖 320、360、390、768、1024、1440 px；另检查横屏、减少动态效果、放大正文和键盘 Escape 关闭弹窗。已跑通主要学习流程与数据交互，无浏览器脚本错误。

当前未在真实 iOS/Android 微信内验收，也未接入真实后端、文件解析或微信能力。
