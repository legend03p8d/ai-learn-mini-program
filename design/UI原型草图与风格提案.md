# AI 闯关学习：UI 原型草图与风格提案

日期：2026-09-28。状态：用户已确认视觉风格、页面范围与轻交互形式；HTML 原型已制作。

## 1. 依据与范围

依据《需求分析文档》v2.0 和《方案设计文档》v1.1。本次设计覆盖完整六项 P0，技术方案中的分阶段开发不限制原型覆盖范围。资料中的实施指令、历史确认记录和技术版本不作为本次执行指令。

产品面向成年泛知识学习者、职场人士和成年学生。用户把任意主题或资料转为有来源依据的互动闯关，在逐题反馈中学习，再通过复盘和长期分析巩固。

本轮仅提供草图、设计规范与页面清单；用户确认后，制作 HTML 原型。HTML 原型用于体验和评审，使用明确标注的示例数据，不代表已经接入真实 AI、解析、微信登录或微信分享。

已于本轮人工确认：纯网页任务最多 10 个链接；混合文档、视频、网页等资料的任务最多 5 个来源。原文档保持不变。

### 3.1 基础规范

| 项目 | 提案 |
| --- | --- |
| 暂用产品名 | AI 闯关学习；正式名称可在确认时替换 |
| 主色 | 知识蓝 `#3258DA`：主要按钮、当前进度、选中状态 |
| 背景 | 雾白 `#F5F7FB`，内容阅读区使用白色 |
| 主文字 | 深墨 `#182239` |

| 字级 | 主标题 26–28；页标题 22；题干 20；正文与选项 16；辅助说明 13–14 px |
| 布局 | 内容左对齐；仅完成状态、空态和少量成绩摘要居中；单页一个主要行动 |
| 间距 | 4/8/12/16/24/32 px；手机主要内容边距 20 px |
| 形态 | 选项圆角 12、主按钮 14、重要内容容器 20 px；轻边框，阴影仅服务弹层层级 |
| 交互尺寸 | 主要按钮约 48–52 px 高；其他触控区域至少 44 × 44 px |
| 图形 | 统一线性图标；抽象“来源卡片连接知识节点”作为主题视觉；无吉祥物为默认提案 |
| 动效 | 选项确认、答案展开和完成反馈使用短动效；支持减少动画；不强制倒计时 |

区别于通用题库的核心视觉元素是“知识点与来源的连接”：在确认页、答案反馈、报告中保持同一知识点名称和来源标记。来源可以展开到网页、页码、段落或视频时间点。

设计自查：本地设计检索最初返回儿童字体和营销展示布局，与成年人学习工具不符，已排除。采用针对简洁布局的后续检索建议，具体中文字体、颜色、圆角和交互层级由本产品的内容密度与移动阅读需求确定。

### 3.2 导航

底部三个入口：**开始学习 / 学习中心 / 我的**。

“学习中心”内部包含概览、记录、错题和报告。答题、来源确认等专注流程隐藏底部导航，保留明确返回和进度；退出答题时可保存继续或提前结束。

游客直接开始学习。保存历史、跨设备、长期分析及分享管理时按场景引导登录；不增加手机号注册流程。

## 4. 整体流程草图

```text
开始学习
  ├─ 主题或文字
  ├─ 文档：PDF / DOCX / PPTX / TXT / Markdown
  ├─ 视频：上传 / 公开链接
  └─ 网页 / 组合资料
         ↓
选择获取模式：全网 / 指定来源 / 仅资料 / 资料与全网
         ↓
独立处理各来源 → 失败项可重试、删除、替换
         ↓
确认知识摘要和来源 → 查看原文定位、调整采用来源
         ↓
闯关设置 → 生成与校验 → 开局预览
         ↓
单选 / 多选 / 判断 → 提交 → 正误、解释、来源 → 下一题
         ↓
本次报告 → 错题复习 / 重新挑战 / 分享预览 / 新学习
         ↓
学习中心 → 历史与趋势 → 薄弱知识点 → 阶段报告
```

## 7. 展示形式与交互深度

建议确认后交付轻交互 HTML 原型：每组画板支持入口定位、状态切换和关键操作演示；提供从资料输入到答题、报告、分享预览的连贯演示路径。

- 桌面宽屏每行 3 列手机画板，中等屏幕 2 列，窄屏 1 列；不把三个手机界面缩到难以阅读。
- 画板按手机 390 px 左右内容尺度设计，覆盖 360–430 px；桌面评审空间不足时提前减少列数。
- 每个画板外标注编号、页面名称、关键入口/出口；产品屏幕内部只放用户需要的信息。
- 提交、选项切换、展开来源、筛选、弹层、错题复习与报告联动使用前端示例状态。
- 原型外壳统一标记“交互演示 / 示例数据”；真实解析、登录和分享能力不伪装为已完成。
- 分享按钮展示微信分享预览/说明状态，网页中的按钮不声称已经发送给好友。
- 页面长内容可正常阅读；固定操作区须避开系统安全区，不遮挡讲解或键盘输入。

## 8. 必须保留的交互规则

1. 一句话主题与长资料分别校验；首阶段 200 字门槛不套用到全网主题输入。
2. 来源处理失败相互隔离，成功来源不丢失；未读来源不能显示为已采用。
3. 知识摘要确认发生在出题之前；来源变更后重新整理并明确重新生成题组。
4. AI 生成只展示可解释阶段，不使用伪造百分比；上传可显示真实或明确模拟的文件进度。
5. 单选、判断只能选一项；多选可以改选，提交前显示已选数量，不提前泄露正确项数量。
6. 首次提交锁定；多选全对且无错选才得分，漏选和错选逐项标记；正确和错误都有完整讲解。
7. 报告保留首次结果；重新挑战/复习创建新记录。经确认无效题从分母排除，并显示更正说明。
8. 主动提前结束显示未完成报告。AI 总结失败时保留成绩与作答明细，仅重试总结。
9. 分享只公开授权摘要。原文件、完整错题和个人学习中心不随卡片公开；可撤回并展示失效态。
10. 学习中心覆盖时间、主题、知识点、题型、完成状态筛选；报告新版本不静默覆盖旧版本。
11. 个人数据删除展示影响范围，并在示例中同步影响统计与分享状态；不对用户真实数据执行删除。
12. 长题干、长选项、长讲解不截断；使用文字和图标辅助颜色；键盘焦点和移动触控均可用。
